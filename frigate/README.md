# Frigate

Detector de pessoas da Fase 1.

## Conteudo

- `config.jetson.yml`: configuracao para Jetson Orin Nano com Logitech C930e.
- `data/`: clips, gravacoes e exportacoes gerados pelo Frigate.
- `models/`: modelos/cache do detector.

## Compose

Os arquivos em `compose/` montam esta pasta no container do Frigate.
